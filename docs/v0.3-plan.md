# v0.3: Get data out

**Date:** 25 October 2026
**Builds on:** `v1-plan.md`. The same principles apply: read-only, bounded, exact values.
**Budget:** app code (excluding tests) stays under 2,000 lines, measured after the pre-release audit.

## Scope

1. **Copy from the grid.**
   - Click a cell to select it. Shift-click selects the rectangle between the two cells.
   - ⌘/Ctrl+C copies the selection as TSV. NULL becomes an empty field. Values containing tabs, newlines or quotes are quoted Excel-style.
   - If any selected cell was truncated at 10 KB, the status line says so and points to Export.
   - Copying text inside an input or the cell viewer still works normally.
2. **CSV export,** from a table tab (with its current search, filters and sort) or a SQL tab (the editor text, or the selection).
   - The server streams every row: no 100/500-row cap and no 10 KB cell cap.
   - It runs in a read-only transaction, with `statement_timeout` raised to 10 minutes for the export only.
   - CSV format follows RFC 4180, with a header row. NULL is written as an empty field and an empty string as `""`, so the two stay distinct.
   - Cancelling the download in the browser cancels the query in Postgres.
   - If an error happens before streaming starts, the tab shows it. A failure mid-stream aborts the download, so a partial file never looks complete.
3. **Query history,** for each connection and database.
   - Each entry records the SQL, the time, the duration and the outcome.
   - Up to 100 entries are kept in the browser (localStorage), newest first. Running the same SQL again moves it to the top.
   - A "History" toggle in SQL tabs shows the list, and clicking an entry loads it into the editor.
4. **Environment label per connection:** none, `dev`, `staging` or `prod`, set in the connection dialog and saved in `connections.json`.
   - The sidebar shows a coloured badge.
   - Tabs of that connection carry the colour: red for prod, amber for staging, green for dev.
   - v0.4 editing will use this for its extra confirmation.
5. **Structure view** (closes a gap from the original spec's Phase 1). A table tab can switch between **Data** and **Structure**. Structure shows:
   - columns: name, type, nullable, default, primary key;
   - indexes, with their definitions;
   - foreign keys in both directions: what this table references, and what references it.

## Out of scope

Saved queries, syntax highlighting, grid keyboard navigation, export formats other than CSV, and import.

## API additions

```
POST /api/c/{id}/{db}/export      form field req = {schema, table, q, filters, sort, desc} | {sql}
                                   → text/csv attachment, streamed
GET  /api/c/{id}/{db}/structure?schema=&table=
                                   → {columns, indexes, foreignKeys, referencedBy}
```

Export is a form POST (not `fetch`), so the browser streams it straight to a file instead of holding it in memory.

## Done when

**Copy**
- Selecting a 2×3 block and pressing ⌘C puts exactly those cells on the clipboard as TSV. NULL becomes empty, and a value with a tab or newline arrives quoted.
- Copying inside the search box or the cell viewer is unaffected.

**Export**
- Exporting `app.events` filtered to `kind = error` gives 250,000 data rows plus a header. Server memory stays flat.
- `public.blobs` exports its full 50,000-character value, not 10 KB.
- `app.users`: NULL and `''` are distinguishable in the file. The int8, numeric, timestamptz, jsonb and bytea values match `psql`.
- A SQL export returns more than 500 rows.
- `DELETE …` through export is refused (read-only).
- Aborting an export mid-stream cancels the query in Postgres within about 2s.

**History**
- Run three queries: they're listed newest first with status and duration.
- History survives a reload, is separate for each connection and database, and is capped at 100.

**Environment**
- A `prod` connection shows a red badge and red tab accents. The setting survives a restart.

**Structure**
- `app.users` lists 9 columns with the correct types, nullability, defaults and PK.
- A table with an index and a foreign key (added to the fixture) shows both. The referenced table lists it under "referenced by".

**Overall**
- `go test ./...` and CI pass.
- App code is under 2,000 lines.
